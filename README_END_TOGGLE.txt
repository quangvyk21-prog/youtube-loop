V10 + END TOGGLE ONLY

Nền: youtube-loop-v10-live-sidebar-end

Chỉ sửa duy nhất hành vi nút end:
- Chưa có end -> bấm end để chọn mốc end.
- Đã có end -> bấm end lần nữa để xóa mốc end.
- Khi xóa end:
  + nút end hết trạng thái sáng
  + auto-loop tạm dừng
  + sidebar quay lại hiển thị end chạy theo thời gian hiện tại
  + bấm end lần nữa để chọn mốc mới

Các phần còn lại giữ nguyên V10.
